# Pre-rationalization archive — 1 September 2026

This tree preserves material moved out of the live repository interface during
the forensic rationalization. Original relative paths are retained beneath
this directory wherever practical.

Contents include superseded runbooks, completed experiment reports, historical
interactive review pages, one-off migration/correction scripts, pre-fix prompt
and data snapshots, mutable pre-canonical estimate/table copies and the old root
manifest. These files are evidence; they are not current run instructions.

`docs/ARCHIVE_MANIFEST.csv` at the repository root records every original path,
destination, action, pre/post SHA-256, tracked state and rationale. Files marked
`delete_recoverably` were not placed here because they contained no unique
scientific evidence; they were moved to
`/tmp/refusal_audit_v2_cleanup_2026-09-01` for short-term recovery.

Do not rewrite frozen manifests inside this archive. Their old paths describe
the historical run correctly; use the archive manifest to map them.

# Multi-router model expansion v2

Status: **Apertus 70B replacement route failed and was set aside; no full expansion
is authorized**. This file preserves the attempted v2 design and must not be
read as an active run instruction. The completed OpenRouter v1 pilot and the
subsequent Hindi audit remain immutable and are documented in
`OPENROUTER_MODEL_EXPANSION_V1.md`.

## Why the roster changed

The v1 pilot found capability failures in 142 of Mistral Small 3.2's 200
responses (71%). Failure was concentrated outside English: 40/40 Hindi, 39/40
Arabic, 33/40 Russian and 29/40 Chinese responses. The model is therefore
removed from future expansion plans. Its completed responses and annotations
are retained as pilot evidence; they are not deleted or rewritten.

The replacement is **Apertus v1.5 70B**, developed by the Swiss AI Initiative.

> attempts and returned one explicit Cloudflare rate-limit response. The

It strengthens European representation and is fully open-weight, multilingual,

## Attempted serving routes

The first attempt pinned Hugging Face's router to the nonprofit Public AI
provider with the exact model ID:

```text
swiss-ai/Apertus-v1.5-70B:publicai
```

The OpenAI-compatible base URL is:

```text
https://router.huggingface.co/v1
```

The provider suffix prevents automatic provider selection. As of 2 September
2026, Hugging Face's live router catalog listed Public AI as the model's only
provider, at $0.82 per million input tokens and $2.92 per million output tokens.
Thinking mode is off by the model's default and is not enabled by the pilot.

The user authorized the frozen 200-request payload and a $4 ceiling. All 200
requests were attempted twice and returned `403 PermissionDeniedError: Your
request was blocked`. No generation completed and provider cost was $0. The
attempts and empty result inventory are retained under
`annotations/model_expansion_v2/apertus_replacement_pilot_v1/`; they are
failed-route evidence, not model outputs.

Dedicated endpoint alternatives were then checked. A 70B deployment was set
aside because it required two H200 GPUs. An 8B AWS CPU deployment never
produced a ready replica. An 8B GCP L4 deployment also remained initializing
during the bounded test window. No audit prompt was successfully generated by
any of these endpoints. All three deployments were paused, so none is an active
route. Private endpoint URLs and account identifiers are kept out of this
document.

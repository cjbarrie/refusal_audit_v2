# Archived Python commands

These programs document completed experiments, failed provider routes and
one-off migrations. They are retained for provenance, but their old relative
paths and environment assumptions are not maintained as a runnable interface.
Use `../SCRIPT_REGISTRY.csv` and `../README.md` for current commands.

- `response_validity/`: pre-adoption DSL and early validity work;
- `model_expansion_pilot/`: the completed OpenRouter pilot, Hindi audit and
  cell-viability decision;
- `model_expansion_failed/`: exhausted Apertus routes;
- `endpoint_setup/`: the old dedicated-endpoint smoke tool;
- `sourcing_corrections/`: a completed prompt-provenance backfill;
- `repository_cleanup/`: the one-off 1 September rationalization utility.
